# Link Eats Printer - Guia do Usuário

## 📥 Como Instalar e Usar

### Instalação Rápida (Versão Portátil)

1. **Descompacte o arquivo** que você baixou (ZIP ou RAR)
2. **Execute o arquivo** `Link-Eats-Printer-Portable.exe`
3. **Pronto!** O aplicativo irá abrir

⚠️ **Importante:** Não precisa instalar nada! Basta executar o .exe

### Instalação Completa (Versão com Instalador)

1. **Execute** o arquivo `Link-Eats-Printer-Setup.exe`
2. **Siga as instruções** do instalador
3. **Atalhos** serão criados automaticamente na área de trabalho e menu iniciar

## 🖨️ Configuração da Impressora

Antes de usar o aplicativo, você precisa ter uma impressora instalada no Windows:

1. Conecte sua impressora ao computador
2. Instale o driver da impressora (geralmente vem no CD ou site do fabricante)
3. Configure a impressora no Windows (Painel de Controle > Dispositivos e Impressoras)
4. Teste a impressora imprimindo uma página de teste do Windows

### Impressoras Compatíveis

O aplicativo funciona com:
- ✅ Impressoras térmicas (recomendado para pedidos)
- ✅ Impressoras convencionais (jato de tinta, laser)
- ✅ Impressoras de rede
- ✅ Qualquer impressora instalada no Windows

## 🚀 Primeiro Uso

### 1. Abrir o Aplicativo
- Execute `Link-Eats-Printer-Portable.exe`
- Aguarde alguns segundos para o aplicativo iniciar

### 2. Fazer Login
Na tela de login, você precisa informar:

- **URL do WebSocket**: Fornecida pela equipe do Link Eats
  - Exemplo: `wss://api.linkeats.com.br/ws`
- **Token de Autenticação**: Fornecido pela equipe do Link Eats
  - Exemplo: `abc123xyz456`

### 3. Configurar Impressão

Após o login, você pode:

- **Ativar Impressão Automática**: Pedidos são impressos assim que chegam
- **Desativar Impressão Automática**: Pedidos ficam na lista para você imprimir manualmente

### 4. Testar a Impressora

Antes de usar, recomendamos testar:

1. Clique no botão **"Testar Impressora"**
2. Uma página de teste será impressa
3. Verifique se a impressão saiu corretamente

## 📋 Usando o Aplicativo

### Recebendo Pedidos

Quando um novo pedido chega:
- 🔔 Você verá uma notificação
- 📝 O pedido aparece na lista
- 🖨️ Se a impressão automática estiver ativa, o pedido é impresso automaticamente

### Imprimindo Manualmente

Para imprimir um pedido da lista:
1. Localize o pedido na lista
2. Clique no botão **"Imprimir"** ao lado do pedido
3. O pedido será enviado para a impressora

### Status de Conexão

No topo da tela, você verá:
- 🟢 **Verde**: Conectado e recebendo pedidos
- 🔴 **Vermelho**: Desconectado
- 🟡 **Amarelo**: Conectando...

## ⚙️ Configurações

### Alterar Impressora Padrão

O aplicativo usa a impressora padrão do Windows. Para alterar:

1. Vá em **Painel de Controle** > **Dispositivos e Impressoras**
2. Clique com botão direito na impressora desejada
3. Selecione **"Definir como impressora padrão"**

### Sair da Conta

Para trocar de conta ou desconectar:
1. Clique no botão **"Sair"** ou **"Logout"**
2. Você voltará para a tela de login

## ❓ Problemas Comuns

### O aplicativo não abre
- Verifique se o arquivo foi descompactado corretamente
- Execute como administrador (clique direito > Executar como administrador)
- Verifique se o Windows Defender não está bloqueando

### Não consigo conectar
- Verifique se a URL do WebSocket está correta
- Confirme se o token de autenticação é válido
- Teste sua conexão com a internet

### Pedidos não imprimem
- Verifique se a impressora está ligada e conectada
- Confirme se há papel na impressora
- Execute o teste de impressora no aplicativo
- Verifique se a impressora está configurada como padrão no Windows

### Impressão sai em branco
- Verifique se há tinta/toner na impressora
- Para impressoras térmicas, verifique se o papel térmico está correto
- Teste imprimir uma página de teste do Windows

### Aplicativo trava ou fecha sozinho
- Reinicie o aplicativo
- Verifique se há atualizações disponíveis
- Entre em contato com o suporte

## 🔒 Segurança

- O token de autenticação é criptografado
